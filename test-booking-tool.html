สร้างตั๋วทดสอบ (Test Booking)

สำหรับทดสอบฟีเจอร์ต่างๆ (เช่น แชร์ตำแหน่งผู้โดยสารให้คนขับ) โดยไม่ต้องรอลูกค้าจองจริง — เขียนเป็น testMode: true แยกจากตั๋วลูกค้าจริงชัดเจน ต้อง login ด้วยบัญชี admin ก่อน

⚠️ ตั๋วนี้เขียนไปที่ bookings/ จริง (ไม่ใช่ testBookings/) เพื่อให้ระบบ sync อัตโนมัติไปยังรายชื่อตั๋วของคนขับได้ถูกต้อง แต่ทำเครื่องหมาย testMode: true ไว้ชัดเจน ลบออกได้ทุกเมื่อจากหน้า Admin Console หรือ Firebase Console
