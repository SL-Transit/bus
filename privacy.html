ข้อมูลที่เว็บไซต์ SL-Transit ใช้

หน้านี้เป็นสรุปสำหรับ Beta Test และจะต้องทบทวนอีกครั้งเมื่อเปิดใช้งานจริง

ข้อมูลที่ผู้โดยสารส่งให้เรา

  • ชื่อ-นามสกุล และเบอร์โทรศัพท์
  • ต้นทาง ปลายทาง วันที่ เที่ยวรถ และจำนวนผู้โดยสาร
  • เลขจอง ราคา วิธีชำระเงิน และข้อมูลการต่อรถ
  • หากเลือก LINE: LINE user ID ชื่อแสดงผล และรูปโปรไฟล์ที่ LINE อนุญาตให้ส่ง

ข้อมูลทางเทคนิค

  • Firebase Anonymous UID เพื่อยืนยันคำขอจอง
  • พื้นที่เก็บข้อมูลในเบราว์เซอร์สำหรับเซสชันและการตั้งค่าความยินยอม
  • สถิติหน้าเว็บแบบใช้อุปกรณ์รหัสสุ่ม จะเก็บเมื่อผู้ใช้ยินยอม Analytics เท่านั้น

ข้อมูลที่หน้าเว็บนี้ไม่ขอโดยตรง

  • รหัสผ่านสำหรับการจองทั่วไป ข้อมูลบัตร และเลขบัญชีธนาคาร
  • ตำแหน่ง GPS แบบเจาะจง เว้นแต่ผู้ใช้เปิดใช้ฟังก์ชันที่เกี่ยวข้อง
  • ข้อมูลสิทธิ์ Admin หรือไฟล์ Excel ต้นฉบับ

การควบคุมของผู้ใช้

ผู้ใช้เลือกยอมรับหรือปฏิเสธ Analytics ได้จากแถบความยินยอม และล้าง/เปลี่ยนการตั้งค่าได้โดยลบข้อมูลเว็บไซต์ในเบราว์เซอร์
