# Decisions — มติและสถานะการตัดสินใจ

## ยืนยันแล้ว

- GitHub `main` เป็นแหล่งโค้ดหลัก
- Admin ใช้ `data/erpDataCenter/adminAccounts/{uid} === true` เป็นแหล่งตรวจสิทธิ์กลาง
- หน้าจองหลักคือ Booking1; `booking.html` เป็นทางผ่านเก่า
- ราคาสำคัญต้องตัดสินจากข้อมูล ERP/เซิร์ฟเวอร์
- จำนวนที่นั่งใช้ตัวนับกลางและธุรกรรม
- ผู้รับ LINE คนขับผูกกับรถที่ `driversByVehicleId/{vehicleId}`
- ผู้ดูแลและคนขับที่ใช้รหัสไลน์เดียวกันต้องได้รับงานแยกบทบาท
- งานแจ้งเตือนใช้รายการงานและกุญแจกันซ้ำ
- ระบบจำลองและการทดสอบโหลดห้ามใช้ฐานข้อมูลจริงและห้ามส่ง LINE จริง

## รอการยืนยัน

- แหล่งข้อมูลทางการของรายได้ การคืนเงิน และยอดแบ่งจ่าย
- วันให้บริการของตารางเวลาและการกรองตามวันจริงในตัวสร้างตารางเผยแพร่
- การเปิดเขียนข้อมูลจริงจากตารางแบบร่างใน Admin ERP
- แหล่งข้อมูลกลางสำหรับเหตุการณ์และสุขภาพระบบ
- การสร้างและสิทธิ์บัญชีเจ้าหน้าที่คนขับในระบบจริง

## ห้ามสรุปเกินหลักฐาน

- ข้อมูลในภาพหน้าจอไม่ใช่ตัวเลขทางการ
- ข้อมูลจำลองไม่ใช่ข้อมูลผู้โดยสารจริง
- การส่งโค้ดขึ้น GitHub ไม่เท่ากับเผยแพร่กฎ Firebase
- การทดสอบระบบจำลองไม่ยืนยันว่าระบบจริงรองรับโหลดเท่ากัน

## ประวัติสำคัญ

- การรวมกฎสิทธิ์ผู้ดูแลถูกระบุว่าเจ้าของเผยแพร่จริงแล้วในเอกสารกลาง
- การผูกรหัสไลน์คนขับกับรถถูกแก้และเผยแพร่ฟังก์ชันที่เกี่ยวข้องแล้ว
- PR #113 ถูกอนุมัติและรวมเข้ากิ่งหลัก
