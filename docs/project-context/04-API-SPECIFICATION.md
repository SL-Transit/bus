# API Specification — ช่องทางเชื่อมต่อ

## Cloud Functions ที่เกี่ยวข้องกับการจอง

| ชื่อ | หน้าที่ | สิทธิ์/ข้อควรระวัง |
| --- | --- | --- |
| `reserveBookingCapacity` | สำรองหรือคืนจำนวนที่นั่ง | ต้องมีสิทธิ์ผู้ใช้ ตรวจข้อมูลเที่ยว จำนวน และรหัสรายการ |
| `createBooking` | สร้างรายการจองและคำนวณยอดฝั่งเซิร์ฟเวอร์ | ต้องมีสิทธิ์ผู้ใช้ ห้ามรับราคาหรือสถานะสำคัญจากผู้ใช้โดยตรง |
| `cancelBooking` | ค้นหาหรือยกเลิกรายการ | ตรวจรหัสรายการกับเบอร์โทรและจำกัดความถี่ |
| `handleBookingCreated` | สร้างงานแจ้งเตือนเมื่อมีรายการจอง | อ่านผู้รับจากรายการกลาง ไม่อ่านจากข้อมูลจอง |
| `handleBookingCancelled` | แจ้งยกเลิกไปยังผู้เกี่ยวข้อง | ป้องกันการส่งซ้ำและไม่ส่งเมื่อสถานะไม่ได้เปลี่ยนเป็นยกเลิก |
| `handleAssignmentChanged` | เติมข้อมูลรถและแจ้งเมื่อเปลี่ยนการมอบหมาย | ผู้รับคนขับมาจากรถที่ถูกมอบหมาย |
| `processNotificationJob` | ส่งงานแจ้งเตือนที่สร้างไว้ | ใช้โทเคนลับฝั่งเซิร์ฟเวอร์และกุญแจป้องกันการส่งซ้ำ |

## Cloud Functions ฝั่งหลังบ้าน

- `readAdminDashboardSummary`: อ่านสรุปแดชบอร์ดตามสิทธิ์และขอบเขต
- `readAdminErpDataCenter`: อ่านข้อมูล ERP ที่ผู้ดูแลได้รับอนุญาต
- `updateAdminErpDataCenter`: แก้ข้อมูล ERP ตามรายการเส้นทางที่อนุญาต
- `publishAdminSchedule`: ตรวจและเผยแพร่ตารางตามขั้นตอนหลังบ้าน
- `updateSystemTestMode`: เปิด/ปิดโหมดทดสอบโดยผู้ดูแล

## เหตุการณ์อัตโนมัติ

- สร้างรายการที่ `/bookings/{code}` → งานแจ้งเตือนการจอง
- สถานะ `/bookings/{code}` เปลี่ยนเป็นยกเลิก → งานแจ้งเตือนยกเลิก
- เปลี่ยน `/bookings/{code}/assignment` → เติมข้อมูลรถและแจ้งผู้รับที่เกี่ยวข้อง
- สร้าง `/operations/notificationJobs/{jobId}` → ส่ง LINE ผ่านเซิร์ฟเวอร์
- สร้าง `/operations/bookingEvents/{code}/checkin/{eventId}` → แจ้งผู้โดยสารตามสิทธิ์ที่กำหนด

## รูปแบบข้อมูลสำคัญ

### ข้อมูลการจอง

ต้องมีอย่างน้อย: รหัสรายการ ผู้ใช้เจ้าของ ชื่อ เบอร์โทร จำนวนคน วันที่ เวลา ต้นทาง ปลายทาง รหัสเที่ยว ราคา จำนวนเงินต่อคน วิธีชำระเงิน และสถานะ

### ข้อมูลผู้รับคนขับ

```text
data/notificationCenter/staffLineTargets
  driversByVehicleId
    {vehicleId}
      {staffRecord}
        active
        staffId
        lineUserId
```

ไม่อนุญาตให้หน้าสาธารณะส่งรหัสไลน์คนขับมาเป็นตัวกำหนดผู้รับ

## การเปลี่ยนแปลง API

การเพิ่มเส้นทางข้อมูลหรือชื่อฟิลด์ใหม่ต้องปรับสัญญา ตัวตรวจสอบ กฎสิทธิ์ การทดสอบ และเอกสารพร้อมกัน ห้ามเพิ่มทางลัดเฉพาะหน้าเว็บ
