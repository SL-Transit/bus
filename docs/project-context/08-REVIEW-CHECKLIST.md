# Review Checklist — รายการตรวจทาน

## ก่อนแก้

- [ ] อ่านบริบทโครงการชุดนี้แล้ว
- [ ] อ่านกระดานงานและไม่ชนกับ AI อื่น
- [ ] ระบุขอบเขตไฟล์และฐานข้อมูลแล้ว
- [ ] ระบุข้อมูลส่วนตัวที่อาจเกี่ยวข้องแล้ว

## ก่อนส่งงาน

- [ ] โค้ดไม่รับราคาหรือสถานะสำคัญจากผู้ใช้โดยตรง
- [ ] สิทธิ์อ่าน/เขียนตรงกับบทบาทและเจ้าของ
- [ ] รหัสไลน์คนขับมาจากรถในรายการกลาง
- [ ] ไม่มีข้อมูลส่วนตัวเต็มใน Log, Test output หรือเอกสาร
- [ ] ไม่มีการสร้างข้อมูลจริงโดยไม่ได้อนุมัติ
- [ ] มีทดสอบพฤติกรรม ไม่ใช่แค่ตรวจข้อความในไฟล์
- [ ] รันชุดทดสอบเดิมแล้วและแยกปัญหาเดิมออกจากปัญหาใหม่
- [ ] ทดสอบโหลดใช้ระบบจำลองหรือระบบทดสอบเท่านั้น
- [ ] ล้างข้อมูลจำลองหลังทดสอบ
- [ ] ตรวจ GitHub Actions และ GitHub Pages เมื่อมีการส่งขึ้น GitHub

## ก่อนรวมงาน

- [ ] มีผลตรวจทานจากเจ้าของหรือผู้รับผิดชอบ
- [ ] ไม่มีปัญหาร้ายแรงหรือสูงที่ยังไม่แก้
- [ ] ระบุสิ่งที่ยังไม่ยืนยันและสิ่งที่ถูกระงับ
- [ ] มีแผนย้อนกลับถ้ากระทบระบบจริง
- [ ] การเผยแพร่ Firebase ได้รับอนุมัติแยกจากการรวมโค้ด
