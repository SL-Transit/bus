# Business Rules — กติกาทางธุรกิจ

## การจอง

- การจองใหม่ต้องมีผู้ใช้ที่ผ่านการยืนยันตัวตน
- เซิร์ฟเวอร์ตรวจรหัสรายการ จำนวนผู้โดยสาร วันที่ เบอร์โทร เที่ยว และราคาจากข้อมูลที่เผยแพร่
- ราคาจากหน้าจอเป็นเพียงข้อมูลประกอบ ต้องตรงกับราคาที่เซิร์ฟเวอร์คำนวณ
- การสำรองที่นั่งต้องทำแบบธุรกรรม และห้ามเกินความจุที่กำหนด
- การสร้างซ้ำด้วยรหัสเดิมต้องถูกปฏิเสธ
- โหมดทดสอบต้องหยุดการจองและการส่งแจ้งเตือนจริง

## การยกเลิก

- ต้องมีรหัสการจองและเบอร์โทรที่ตรงกับรายการ
- การยกเลิกต้องเปลี่ยนสถานะอย่างมีเงื่อนไขและคืนจำนวนที่นั่งจากรายการเดิม
- การแจ้งยกเลิกต้องไม่ส่งซ้ำโดยไม่จำเป็น

## ราคาและการชำระเงิน

- ผู้ใช้แก้ราคาสุดท้ายหรือสถานะชำระเงินเองไม่ได้
- การชำระปลายทางและการโอนเงินต้องมีสถานะคนละแบบ
- หลักฐานการชำระเงินและข้อมูลการเงินเป็นข้อมูลจำกัดสิทธิ์
- รายได้ การคืนเงิน และยอดแบ่งจ่ายยังต้องใช้แหล่งข้อมูลที่ยืนยันแล้วก่อนนำมาเป็นตัวเลขทางการ

## รถ คนขับ และแจ้งเตือน

- `vehicleId` จากการมอบหมายที่ผ่านศูนย์กลางเป็นตัวระบุรถ
- คนขับรับแจ้งเตือนจาก `driversByVehicleId/{vehicleId}` เท่านั้น
- ห้ามใช้ `driverLineId`, `lineUserId` หรือรหัสผู้รับจากข้อมูลการจอง ตารางเวลา หรือฟอร์มสาธารณะ
- คนขับต้องใช้รหัสผู้ใช้ไลน์ส่วนตัว ไม่ใช้รหัสกลุ่มหรือห้องแทนโทรศัพท์คนขับ
- หากผู้ดูแลและคนขับใช้รหัสเดียวกัน ให้แยกงานตามบทบาทเพื่อให้ตรวจสอบได้

## ข้อมูลส่วนตัว

- ใช้ชื่อและเบอร์โทรเท่าที่จำเป็นต่อการให้บริการ
- ห้ามแสดงรหัสไลน์เต็ม เบอร์โทรเต็ม รหัสผ่าน บัญชีธนาคาร หรือข้อมูลผู้โดยสารส่วนตัวในแดชบอร์ดที่ไม่จำเป็น
- ผลทดสอบและบันทึกระบบต้องใช้ข้อมูลจำลองหรือปกปิดบางส่วน
