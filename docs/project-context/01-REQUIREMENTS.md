# Requirements — ข้อกำหนดโครงการ

## เป้าหมาย

SL-Transit เป็นระบบจัดการการเดินรถและการจองที่ต้องรองรับผู้โดยสาร ผู้ดูแล คนขับ และศูนย์ข้อมูลกลาง โดยข้อมูลสำคัญต้องมาจากแหล่งกลาง ไม่ใช่จากหน้าจอใดหน้าจอหนึ่ง

## ขอบเขตระบบ

- หน้าสาธารณะ: หน้าแรก ข้อมูลการเดินทาง การจอง ตรวจตั๋ว ยกเลิก และติดตามการเดินทาง
- ศูนย์หลังบ้าน: Admin ERP, แคตตาล็อก จุดจอด เส้นทาง ราคา ตารางเวลา คิว รถ คนขับ การจอง การเงิน สิทธิ์ การทดสอบ และบันทึกตรวจสอบ
- ระบบคนขับ: แอปคนขับ ตำแหน่งรถ งานประจำวัน การตรวจตั๋ว และคำสั่งควบคุมรถ
- ระบบเชื่อมต่อ: Firebase Authentication, Realtime Database, Cloud Functions, LINE และการแจ้งเตือนภายใน

## ข้อกำหนดความปลอดภัย

- การอ่านและเขียนต้องแยกตามบทบาทและความเป็นเจ้าของ
- ราคาสุดท้าย จำนวนที่นั่ง สถานะการชำระเงิน และสถานะการจองต้องตัดสินที่เซิร์ฟเวอร์
- ผู้ใช้จากหน้าจอห้ามกำหนดผู้รับแจ้งเตือนของผู้ดูแลหรือคนขับเอง
- รหัสไลน์ของคนขับต้องผูกกับรถในรายการกลาง ไม่ผูกกับตารางเวลา หรือข้อมูลการจองจากหน้าจอ
- ข้อมูลส่วนตัวต้องแสดงเท่าที่จำเป็นและไม่ลงในบันทึกทดสอบแบบเต็ม
- การยกเลิกต้องตรวจรหัสการจองกับเบอร์โทร และต้องคืนจำนวนที่นั่งอย่างปลอดภัย

## ข้อกำหนดการเปลี่ยนแปลง

- งานที่กระทบระบบจริงต้องมีแผน หลักฐานทดสอบ และการอนุมัติ
- กฎฐานข้อมูลและการตั้งค่า Firebase ไม่ได้เผยแพร่ตามการส่งโค้ดขึ้น GitHub อัตโนมัติ
- งานที่เป็นเอกสารอย่างเดียวห้ามเปลี่ยนโค้ดรันจริง ห้ามเขียน Firebase และห้ามเผยแพร่ระบบ
